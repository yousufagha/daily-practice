# daily-practice

Running log of daily reps: LeetCode-style DS/ML screening problems and Kaggle competition work. Updated continuously — this is the commit habit that keeps the contribution graph active while studying for AI-103 and Palantir Foundry Data Engineer.

## Structure

`leetcode/` holds one file per problem, named by date and topic. Focus areas: SQL joins and window functions, pandas-style data manipulation, stats/probability, easy-medium arrays and hashmaps — the patterns that show up in DS/ML screening interviews, not general algorithm puzzles.

`kaggle/` holds notebooks per competition round, starting with a Playground Series entry.
